## 2. Crawler Access Configuration

### `src/app/robots.ts`
- **User-Agent:** `*` (All compliant search engine bots: Googlebot, Bingbot, DuckDuckBot, Applebot).
- **Allowed:** `/` (All public pages, assets, stylesheets, and scripts required for rendering).
- **Disallowed:** `/api/` (Protects internal serverless endpoints from wasteful crawler crawls).
- **Sitemap Reference:** Absolute HTTPS link to `/sitemap.xml`.

## 3. Metadata & OpenGraph Standards

### Implemented Helper: `src/lib/metadata.ts`
All routes receive:
1. `title`: Page-specific title with brand suffix.
2. `description`: Descriptive summary under 160 characters.
3. `alternates.canonical`: Absolute canonical URL preventing duplicate indexing across query parameters.
4. `openGraph`:
   - `og:title`, `og:description`, `og:url`, `og:siteName`, `og:locale: "en_IN"`.
   - `og:image`: High-res 1200x630 card at `/assets/og-image.png`.
5. `twitter`:
   - `card: "summary_large_image"`.
   - `creator: "@AniketYadav1105"`.
   - `site: "@AniketYadav1105"`.

## 5. Performance & Image Strategy

- **Next.js `<Image>`:** Automatic responsive WebP / AVIF transcoding.
- **LCP Optimization:** Hero profile avatar and initial banner use priority loading, preventing late layout shifts.
- **Fixed Aspect Ratios:** All card containers maintain explicit aspect ratios (`16/9`, `16/10`, `4/3`) ensuring **Zero Cumulative Layout Shift (CLS < 0.05)**.
- **Shared JavaScript Chunks:** First Load JS is optimized to ~102 kB.
