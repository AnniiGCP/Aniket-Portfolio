## Introduction

**CodeBrain AI** is an intelligent developer acceleration and codebase comprehension tool built to eliminate the steep onboarding curve of large, complex, and legacy software repositories. Rather than treating source code as plain text, CodeBrain integrates concrete syntax tree parsing via Tree-sitter with dense semantic vector indexing and Large Language Model reasoning.

It empowers software engineers, engineering managers, and open-source contributors to query unfamiliar codebases in natural language, generate living architectural documentation, and autonomously diagnose CI/CD build failures with pinpoint pull request comments.

## Why I built it

Every software engineer knows the friction of cloning a multi-thousand-file repository and trying to answer basic architectural questions: "Where does this session token get validated?", "Which microservice handler handles this webhook event?", or "Why did this CI/CD build fail in the staging environment?"

Standard code search tools like `grep` only match exact string patterns, while general-purpose AI chat tools lack structural awareness of Abstract Syntax Trees, file dependency graphs, and call hierarchies. I wanted to build a developer tool that bridges this gap—combining syntax-level AST understanding with vector retrieval and continuous integration diagnostics.

## Core features

- **Natural language codebase search:** Ask semantic and structural questions about any cloned repository and receive answers with exact file citations.
- **AST-aware code chunking:** Parse code hierarchically using Tree-sitter so functions, classes, and scopes are indexed as coherent logical units rather than arbitrary token blocks.
- **Hybrid vector & symbol retrieval:** Combine FAISS dense semantic embeddings with lexical symbol lookup for identifier resolution.
- **Automated living documentation:** Generate up-to-date Markdown architecture guides and component interaction maps directly from source code.
- **CI/CD diagnostic integration:** Capture Jenkins and GitHub Actions failure logs via webhooks, isolate the failing commit diff, and generate root-cause explanations.
- **Interactive developer workspace:** Clean React and TypeScript web interface featuring Monaco Editor code highlighting and split-pane response inspection.
- **Contract-first API backend:** Built with FastAPI and Pydantic v2 schemas for strict boundary validation and automatic OpenAPI documentation.

## How it works

1. **Repository ingestion & cloning:** The backend accepts a local path or repository URL and discovers all supported source files (Python, TypeScript, JavaScript, Go).
2. **Syntax tree extraction:** Tree-sitter parses the concrete syntax tree, extracting class declarations, function signatures, docstrings, and import graphs.
3. **Semantic embedding & indexing:** Code symbols and contextual scopes are transformed into vector embeddings and indexed in FAISS alongside a lexical symbol registry.
4. **Context retrieval & synthesis:** When a developer submits a query, CodeBrain retrieves the most relevant code blocks, resolves dependencies across files, and constructs a grounded prompt.
5. **Answer delivery:** The reasoning model produces a structured explanation with exact line ranges, symbol cross-references, and code snippets.
6. **CI/CD webhook evaluation:** On build failure, the diagnostic endpoint parses terminal logs, matches stack traces against indexed symbols, and suggests concrete patches.

## System architecture

CodeBrain AI uses a modular client-server architecture:
- **Frontend layer:** Built with React, Next.js, and TypeScript, styled with Tailwind CSS, providing responsive query consoles and syntax-highlighted code diff viewers.
- **Service layer:** Asynchronous Python backend powered by FastAPI and Uvicorn, handling concurrent repository parsing tasks and streaming responses.
- **Parser & indexer:** Tree-sitter bindings for multi-language AST generation paired with FAISS for sub-millisecond similarity search across thousands of vectors.
- **Packaging:** Dockerized services managed via Docker Compose for consistent local development and isolated execution environments.

## Engineering challenges

### AST parsing across heterogeneous languages
Different programming languages structure functions, methods, and modules differently. Building a unified symbol schema that accurately represents Python decorators, TypeScript interfaces, and Go structs required custom Tree-sitter query patterns for each grammar.

### Chunking code without losing context
Splitting code on arbitrary character or token limits frequently breaks functions in half or separates decorators from their handlers. CodeBrain implements AST-guided chunking that preserves entire logical scopes and appends parent class signatures to nested methods.

### Eliminating hallucinated file paths
General LLMs frequently invent non-existent file paths or function names. By strictly enforcing that every model generation cites only chunks present in the FAISS retrieval context, CodeBrain maintains grounded accuracy.

## Future improvements

- **Call graph visualization:** Interactive node-link graphs displaying call paths between functions and microservices.
- **Incremental indexing:** Re-indexing only modified files on Git commit rather than full-repository scans.
- **IDE extensions:** Direct integration into VS Code and JetBrains IDEs for inline questions while editing.
- **Self-hosted embedding models:** Local quantization support using Ollama or ONNX Runtime for fully offline developer privacy.

## What I learned

Building CodeBrain AI taught me that effective AI developer tools require deep integration with compiler and parser fundamentals. Large language models become exponentially more useful when paired with authoritative deterministic systems like Abstract Syntax Trees and strict schema validation.
