## Overview

A comprehensive engineering repository containing over 100 tested, production-ready Bash automation scripts, Terraform provisioning templates, and cloud architecture patterns developed while mastering the **Google Cloud Platform (GCP)** ecosystem.

## Domains Covered

- **Compute & Containers:** Automated provisioning of Google Kubernetes Engine (GKE) clusters, Cloud Run container services, and Compute Engine VM instance groups.
- **Data & Analytics:** BigQuery partitioned table creation, dataset ETL pipelines, and streaming ingestion setups.
- **Networking & Security:** VPC network peering, firewall rules automation, IAM least-privilege role bindings, and Cloud Armor security policies.
- **DevOps & CI/CD:** Cloud Build trigger setups, container artifact management in Artifact Registry, and automated health probing.
